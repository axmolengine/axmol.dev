Axmol 3.0.0-beta1 即将发布 了解 v3 预览

开源 · 代码优先 · 跨平台

Axmol

面向移动端、桌面端、Xbox 与 WebAssembly 的现代 C++ 游戏开发。

探索 Axmol 3 Beta 下载 2.11.4 LTS 查看文档

// 一套 C++ 代码，运行在多个平台 auto scene = ax::Scene::create(); auto player = ax::Sprite::create("player.png"); scene->addChild(player);

为什么选择 v3

一套引擎，拓展更多边界。

现代图形

以 HLSL 为核心，通过 Dynamic RHI 覆盖 D3D、Vulkan、Metal 与 OpenGL。

现代 C++

采用 C++23，更新核心、构建工具链和开发工作流。

更多平台

支持 ARM、OpenXR、移动端、桌面端、Xbox 与 WebAssembly。

清晰的渲染路径

一套着色器，适配多个图形后端。

只需编写一份 HLSL，再由 axslcc 编译为 D3D11、D3D12、Vulkan、Metal 和 OpenGL 所需的着色器。
