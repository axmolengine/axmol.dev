公开预览 · 3.0.0-BETA1

Axmol 3 即将到来。

焕新的引擎核心、渲染栈与平台能力，为下一代跨平台游戏而来。

查看路线图 阅读构建指南 规划迁移
即将发布

3.0.0-beta1

正式 tag 发布后，我们才会在这里加入下载链接。

关注发布讨论

核心升级

为下一代项目打好基础。

C++23

更新语言基线、引擎核心与工具链。

现代 RHI

通过 Dynamic RHI 统一 D3D11、D3D12、Vulkan、Metal 与 OpenGL。

HLSL Shader

维护一份 Shader 源码，为不同渲染后端编译。

ARM 与 OpenXR

覆盖 ARM 桌面系统、OpenXR 场景和控制器输入。

新物理系统

Box2D 3.x 支持 2D，JoltPhysics 5.x 支持 3D 场景。

输入与性能分析

Pointer Events 与 Tracy profiling 改善开发体验。

迁移指南

迁移前先了解变化。

从 Axmol 2、Cocos2d-x、Shader、Input 和 Physics 迁移，请查看对应索引。

Axmol 2 → 3 重命名与移除的 API
Cocos2d-x → Axmol 命名空间与项目迁移
Shader 迁移 从 GLSL 工作流迁移到 HLSL
Input 迁移 采用 Pointer Events
