パブリックプレビュー · 3.0.0-BETA1

Axmol 3 が登場します。

次世代のクロスプラットフォームゲームに向けた、刷新されたエンジンコア、レンダリングスタック、プラットフォーム対応。

ロードマップを見る セットアップガイドを読む 移行を計画する
まもなく公開

3.0.0-beta1

このページはリリース発表の準備ができています。公式タグの公開後にのみダウンロードリンクを追加します。

リリースの議論をフォロー ビルドガイド

新機能

v3 の基盤。

C++23

刷新されたエンジンコアとツールチェーンにより、言語の基準を C++23 へ進めます。

Modern RHI

Dynamic RHI 選択により、Metal と OpenGL に D3D11、D3D12、Vulkan が加わります。

HLSL シェーダー

1つのシェーダーソースを維持し、対応する各レンダリングバックエンド向けにコンパイルします。

ARM + OpenXR

OpenXR のシーン構成とコントローラー入力に加え、Windows と Linux の ARM 対応を提供します。

新しい物理演算

2D 物理には Box2D 3.x、3D シーンには JoltPhysics 5.x を使用します。

入力とプロファイリング

Pointer Events とコンパイル時に選べる Tracy プロファイリングで開発サイクルを改善します。

移行

切り替える前に準備しよう。

Axmol 3 では非推奨 API を削除し、複数のコアシステムを変更します。該当する移行手順から始めてください。

Axmol 2 → 3 名前変更・削除された API
Cocos2d-x → Axmol 名前空間とプロジェクトの移行
シェーダー移行 GLSL ワークフローから HLSL へ移行
入力の移行 Pointer Events を採用
