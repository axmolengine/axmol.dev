ЧТО НОВОГО

Основа v3.

C++23

Базовый стандарт языка переходит на C++23 с обновлённым ядром движка и инструментами.

Modern RHI

D3D11, D3D12 и Vulkan присоединяются к Metal и OpenGL с выбором Dynamic RHI.

HLSL-шейдеры

Поддерживайте единый исходный код шейдера и компилируйте его для каждого поддерживаемого бэкенда рендеринга.

ARM + OpenXR

Поддержка ARM для Windows и Linux вместе с компоновкой сцен OpenXR и вводом с контроллеров.

Новая физика

Box2D 3.x обеспечивает 2D-физику, а JoltPhysics 5.x поддерживает 3D-сцены.

Ввод и профилирование

Pointer Events и выбираемое при компиляции профилирование Tracy улучшают процесс разработки.

Подготовьтесь перед переходом.

Axmol 3 удаляет устаревшие API и меняет несколько основных систем. Начните с подходящего пути ниже.

Axmol 2 → 3 Переименованные и удалённые API
Cocos2d-x → Axmol Миграция пространства имён и проекта
Миграция шейдеров Переход с GLSL на HLSL
Миграция ввода Перейти на Pointer Events

Бета-версия означает обратную связь.
