NOVEDADES

La base de v3.

C++23

La base del lenguaje avanza a C++23 con un núcleo y una cadena de herramientas renovados.

Modern RHI

D3D11, D3D12 y Vulkan se unen a Metal y OpenGL, con selección Dynamic RHI.

Shaders HLSL

Mantén una fuente de shader y compílala para cada backend de renderizado compatible.

ARM + OpenXR

Compatibilidad ARM para Windows y Linux junto con composición de escenas OpenXR y entrada de controladores.

Nueva física

Box2D 3.x impulsa la física 2D y JoltPhysics 5.x admite escenas 3D.

Entrada y perfilado

Pointer Events y el perfilado Tracy seleccionable en tiempo de compilación mejoran el ciclo de desarrollo.

MIGRACIÓN

Prepárate antes de cambiar.

Axmol 3 elimina API obsoletas y cambia varios sistemas principales. Empieza por la ruta adecuada.

Axmol 2 → 3 API renombradas y eliminadas
Cocos2d-x → Axmol Migración de espacio de nombres y proyecto
Migración de shaders Pasar de flujos GLSL a HLSL
Migración de entrada Adoptar Pointer Events
